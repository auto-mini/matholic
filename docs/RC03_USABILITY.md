# RC03 사용성 개선

작성일: 2026-07-25 (Asia/Seoul)

RC02 운영 인수시험 뒤 관리자 단독 사용에서 확인한 불편을 개선한다.
이 문서는 구현 결과와 자동 검증, 아직 수행하지 않은 A 기기 실기를 구분한다.

## 확정 동작

### 학생과 반

- 학생은 전체 이름, 매쓰홀릭 아이디와 비밀번호로 먼저 한 번 등록한다.
- 반별 학생 구성 화면에서 학생 마스터 목록의 여러 학생을 선택한다.
- 한 학생은 여러 반에 동시에 소속될 수 있고 모든 반에서 같은 QR을 사용한다.
- 반 삭제는 반과 그 반의 소속 관계만 삭제하며 학생, 자격정보와 QR은 보존한다.
- 로그인 정보 변경은 별도 창에서 새 아이디, 새 비밀번호와 비밀번호 확인값을 받는다.
- 수업 전에도 이번 수업에만 추가할 보강 학생을 선택할 수 있다.

### QR 카드와 전달

- 출력 문서는 A4 한 페이지 중앙에 실제 크기 65×90mm 세로 카드를 배치한다.
- 카드 안 QR은 30×30mm이고 상단에는 학생 전체 이름을 표시한다.
- 마스킹 표시명 입력·표시 동작은 제거했다. 기존 DB의 열은 스키마 v1 무중단
  호환을 위해서만 남기고 전체 이름을 동일하게 저장한다.
- Android 인쇄 서비스 직접 전송과 별도로 `카드 크기 PDF 공유·저장`을 제공한다.
- PDF는 Quick Share 등 Android 공유 대상에 전달할 수 있고 앱 cache의 임시본은
  복귀 뒤 삭제한다.

### QR 대기 화면

- QR 인식은 전면·후면 카메라를 선택할 수 있지만 카메라 미리보기는 표시하거나
  저장하지 않는다.
- 화면에는 QR을 맞출 위치와 현재 상태만 표시한다.

### Web 학생 화면

- 학생 확인이 끝나면 학습지 페이지를 자동으로 연다.
- 목록 화면 위에는 `학습지`와 `진단평가` 두 전환 버튼만 제공한다.
- 학생 모드의 상위 주소는 학습지, 진단평가와 문제 화면으로 제한한다.
- Android 뒤로가기는 항상 소비하고 시스템 탐색 막대는 숨김 상태를 재적용한다.
- 로그인·로그아웃·복구 중 WebView를 숨기고 완전 불투명 차단 화면만 표시한다.
- 기존 중앙 상단 상태 배지는 학생 화면에 표시하지 않는다.
- 문제 화면의 입력칸, 수식 입력 버튼, 모름·다음 문제·답안 제출 버튼의 최소
  터치 영역과 글자 크기를 늘리고 문제 영역에 위·아래 여백을 보강한다.
- 전체답안 화면의 최종 제출 버튼은 화면 하단에 고정한다.
- 종합분석 화면은 의미 구조가 확인된 경우 즉시 불투명 보호 화면으로 가리고,
  틀린 문제 번호 목록만 표시한다. `확인하고 채점 끝내기`를 누르면 자동
  로그아웃하고 Kiosk의 QR 대기로 복귀한다.

### 수업 시작·종료

- 수업 시작은 먼저 남은 Web 세션을 안전 정리하고 성공한 경우에만 선택한 반
  수업을 시작한다.
- 수업 종료는 먼저 Web 로그아웃과 정리를 끝내고 성공한 경우에만 현재 수업과
  일회성 보강 명단을 종료한다.
- 정상 관리자 흐름에서 별도의 `Web 세션 안전 정리` 단계를 요구하지 않는다.

## A 기기에서 확인할 항목

1. 기존 RC02 DB가 유지된 상태에서 학생·반 목록이 정상 로드되는지
2. 학생 한 명을 두 반에 넣고 동일 QR로 각 반 수업에 진입하는지
3. 한 반 삭제 뒤 학생과 QR이 다른 반에서 유지되는지
4. 65×90mm 카드와 30×30mm QR이 실제 크기로 출력되는지
5. PDF를 Quick Share로 PC에 직접 보낼 수 있는지
6. 전면·후면 카메라 모두 미리보기 없이 QR을 인식하는지
7. 자동 학습지 진입과 학습지↔진단평가 전환이 되는지
8. 문제 입력·모름·다음·두 답안 제출 버튼이 충분히 커졌는지
9. 종합분석 상세 내용 없이 오답 번호만 보이고 확인 뒤 QR 대기로 복귀하는지
10. Web 학생 화면에서 뒤로가기·홈·최근 앱·알림창으로 이탈하지 않는지
