새 기능을 제안하거나 구현 범위를 정할 때 이 문서를 먼저 확인한다.

### 30번 대체 결정: 사용자용 지원자료 내보내기 금지

- 개인정보 제거 지원자료를 사용자 화면에 표시하거나 사용자가 직접
  내보내는 기능은 만들지 않는다.
- 같은 목적의 자료가 디버깅에 필요하면 앱 내부 진단 로그로만 남긴다.
- 진단 로그에는 학생 아이디·비밀번호, QR 원문, 답안, 점수, 학습지 내용,
  Web 페이지 원문과 학생 전체 이름을 기록하지 않는다.
- 로그는 앱 private storage에 보관하고 크기·기간을 제한한다.
- 운영 UI에는 로그 열람·공유·내보내기 버튼을 만들지 않는다.
- 개발자가 명시적인 디버깅 작업을 수행할 때만 ADB 등 개발 경로로 읽는다.
